# Initialize Rail Node Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Ship the Initialize rail node — a gatekeeper that sits between trigger and first task, collecting required manifest data and post-holder assignments before the rail can start. Per spec `docs/superpowers/specs/2026-05-11-initialize-node-design.md`.

**Architecture:** One new `rail_nodes.type` value + one new `RailNodeConfig` variant; one new `rail_runs.post_holder_assignments` JSONB column. New `prepareStartRail` query and a Start Rail modal extend the runtime; existing `startRail` action gains an optional `initializeData` input + validation; cycle issuance respects `post_holder_assignments` when populated.

**Tech Stack:** Next.js 16, Drizzle ORM, next-safe-action with `orgAction`, shadcn/Tailwind, Vitest, Playwright.

- [ ] **Step 2: Validation block inside startRail**

After existing rail/particle validation, BEFORE creating the run:

```typescript
// Find Initialize node, if any
const initializeNode = nodesByPosition.find((n) => n.type === "initialize")

if (initializeNode) {
  if (!parsedInput.initializeData) {
    throw new ActionError("VALIDATION", "This rail requires Initialize data.")
  }
  const init = parsedInput.initializeData

  // 1) Manifest fields: every required slug must have a non-empty value
  const requiredSlugs =
    initializeNode.config.kind === "initialize"
      ? initializeNode.config.requiredManifestFieldSlugs
      : []
  for (const req of requiredSlugs) {
    const data = init.manifestData[req.manifestId] ?? {}
    const v = data[req.fieldSlug]
    const empty = v === undefined || v === null || v === "" || (Array.isArray(v) && v.length === 0)
    if (empty) {
      throw new ActionError("VALIDATION", `Required field not filled: ${req.fieldSlug}`)
    }
  }

  // 2) Post-holder assignments: every multi-holder Post on the rail must have one
  //    AND the assigned userId must currently hold the Post
  const postIdsOnRail = new Set(nodesByPosition.map((n) => n.postId).filter(Boolean) as string[])
  for (const postId of postIdsOnRail) {
    const holders = await ctx.db
      .select({ userId: postAssignments.userId })
      .from(postAssignments)
      .where(eq(postAssignments.postId, postId))
    if (holders.length <= 1) continue // single-holder or empty — not in Initialize's scope

    const assigned = init.postHolderAssignments[postId]
    if (!assigned) {
      throw new ActionError("VALIDATION", `Pick a holder for post ${postId}`)
    }
    const ok = holders.some((h) => h.userId === assigned)
    if (!ok) {
      throw new ActionError("FORBIDDEN", `Assigned user does not hold post ${postId}`)
    }
  }
}
```
